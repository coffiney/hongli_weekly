# 红利股周报系统 hongli_weekly

## 一、这是什么

**一句话**：每个周五傍晚，这台小机器会自动把 119 只 A 股「高分红股票」（红利股）体检一遍，算出谁便宜、谁贵、谁有雷，再生成一份人话周报发给你。

通俗点说：你有一篮子「靠分红赚钱的公司股票」。**分红**就像收房租——你买了房子（股票），公司每年把赚到的钱分一部分给你，这就是股息。红利股就是那些「房东」很稳、年年都给你发钱的公司。但「分红高」不代表「划算」，本系统就是帮你在买之前先看清楚：这房租（股息）是真香，还是看着香、其实是个坑。

它不替你下单，只把客观数据摆清楚，再让大模型（只负责说人话、不负责算数）写一段点评。最终产出的 [HTML 周报](https://coffiney.github.io/hongli_weekly/) 任何人都能看懂。

## 二、它帮你避开的两个大坑

普通人买红利股，最容易栽在这两个坑里：

1. **「股息率陷阱」——看着利息高，其实是股价跌出来的。**
   股息率 = 每股分红 ÷ 股价。如果公司分红没变，但股价大跌，这个比率反而会「升高」。就像一套房子租金没变、房价腰斩，租售比（股息率）显得特别诱人——但房子本身在贬值。系统用「利率中性估值」把这种「假高息」揪出来（见第四节因子 2）。

2. **「价值陷阱」——便宜，但公司本身有雷。**
   有些股票市盈率很低、股息率很高，看着像捡漏，其实公司赚的是「纸面富贵」：利润没有变成真金白银，或者分红快分不动了。系统专门用一个黄色警示格（low_C）把这些「便宜但有雷」的标的圈出来，明确不进买入候选（见第五节）。

## 三、它每周怎么工作（像做一道菜）

每周五 18:00 左右，流水线自动起锅：

| 步骤 | 干啥 | 大白话 |
|---|---|---|
| ① 拉数据 | 从银河证券 SDK + 东方财富拉行情/财报/分红/现金流 | 去菜市场把新鲜食材（数据）买回来 |
| ② 打分 | 五因子算法给每只股票算 5 个 0–1 的分 | 按食谱逐项的评分 |
| ③ 分类 | 估值×质量九宫格落格 | 把菜分到「好吃/普通/慎点」三档 |
| ④ 定价 | 算客观买卖参考价（价格锚） | 标出这菜「低于这价划算、高于那价偏贵」 |
| ⑤ 点评 | 大模型（只解读、不算数）写点评 | 请个解说员用大白话念一遍 |
| ⑥ 发布 | 生成 HTML 周报 → GitHub Pages → 飞书群通知 | 上菜 + 喊你来看 |

全程固定算法、结果可重放；拉完数据立刻断开数据源连接（logout 铁律）。

## 四、五因子，逐一说人话

每个因子得分都在 0–1 之间，**越接近 1 越好**。

**① 可持续股息率（sus_yield）——「长期能收到多少租」**
- 是什么：用公司近 5 年「中等水平」的每股盈利（EPS，见[小词典](#六专有名词小词典)）× 它能长期维持的派息比例，反推它「正常年份」能分你多少钱，再除以现价。
- 为什么重要：单看今年股息率会被某年特殊分红带偏；取 5 年中位数更稳，专治「追高息率」冲动。
- 好坏：比率越高，以当前股价买、长期收租越划算。

**② 利率中性估值（s_val）——「撇开大环境，这房租到底贵不贵」**
- 是什么：把「股息率减去 10 年期国债利率」的差值，放在这只股票自己过去 5 年的历史上排座次。再叠加一层「当前利率处在极端位置就剥离利率周期影响」的修正。
- 为什么重要：国债利率一降，所有股票股息率都显得高，易误判「变便宜了」。这因子把利率周期影响剥掉，只看股票自身贵贱。
- 好坏：`s_val < 0.40` 低估，`0.40–0.65` 合理，`> 0.65` 高估。

**③ 分红可持续性（s_sus）——「这房租收得稳不稳」**
- 是什么：综合派息比例是否健康（30%–70% 最佳）、现金流对分红的覆盖、以及连续分红年数。
- 为什么重要：把利润全分光（派息比例过高）或现金流跟不上，明年可能就降租甚至断租。
- 好坏：连续分红越久、现金流越能盖住分红，分越高。

**④ 周期定位（s_cyc）——「现在是淡季买还是旺季买」**
- 是什么：看当前盈利在自己过去 10 年历史里排什么位置。盈利处在历史低位（周期底部），这分反而高。
- 为什么重要：煤炭、钢铁等周期行业盈利忽高忽低，在「淡季」（盈利低、股价也低）买比「旺季」追高安全。
- 好坏：当前 EPS 处在自身历史低位 → 分高（逆向更划算）。

**⑤ 质量（s_q）——「这房东靠不靠谱」**
- 是什么：ROE（钱生钱的效率，见[小词典](#六专有名词小词典)）的 5 年中位数 + 稳定性 + 连续分红年数。
- 为什么重要：同样的分红，背后是高效赚钱的好公司还是靠借债硬撑，天差地别。
- 好坏：ROE 高且稳、连续分红久 → 分高（标记为质量 A）。

## 五、报告怎么读

### 1）九宫格怎么定位
横轴是「相对质量」（A 强 / B 中 / C 弱），纵轴是「估值」（低 / 合理 / 高）。重点记住三格：

| 格子 | 含义 | 颜色 |
|---|---|---|
| **low_A 低估·质优** | 又便宜又好，核心候选 | 深绿 |
| **low_C 陷阱警示** | 便宜但有雷，**不进买入建议** | 黄 |
| **high_C 高估·质弱** | 又贵又弱，规避 | 暗红 |

报告顶部还有「候选标的」表，只列 low_A / low_B / mid_A 这几格里综合分最高的。

### 2）买卖参考价怎么用
每只候选股给出 **买入参考价 / 卖出参考价**，由五个客观「价格锚」共同定出（取多个锚里最便宜的当买入线，最贵的当卖出线，且卖出不超过买入的 1.6 倍）：

- **A 股息率锚**：按「4.5% 目标息率」反推的价钱——低于它，你拿到的息率就高于 4.5%。
- **G 戈登锚**：用分红贴现模型（DDM）估算的内在价。
- **B 区间锚**：近 52 周价格区间里偏低 30% 的位置。
- **C 收益率下限锚**：按 4.5% 息率下限守住的价。
- **D 综合分反解锚**：倒推出「综合分达到 40 分」对应的价格。

> 用法：现价在「买入价」下方偏划算，上方偏贵，中间为持有区间。例：交通银行（601328）现价 7.28，正好等于买入价，低波且股息率 7.58%，系统判「可买入」。

### 3）各种标记对照表

| 标记 | 含义 |
|---|---|
| ✅ 低波 | 近 52 周年化波动率 ≤ 25%，价格起伏小、睡得着觉 |
| ⚠️ 波动 | 波动率 > 25%，价格上蹿下跳 |
| 🔥 加速线 | 股息率 > 5.5% **且**低波——又高息又稳，重点关注 |
| 现金流✅✅ | 经营现金流/净利润 ≥ 1.5，利润是真金白银（优秀） |
| 现金流✅ | 该比值 ≥ 1.0，合格 |
| 现金流⚠️ | 比值介于 0.6–1.0，利润含金量一般 |
| 现金流❌ | 比值 < 0.6（甚至为负，如民生银行 -5.15），利润可能是纸面富贵——价值陷阱信号 |

## 六、专有名词小词典

| 词 | 大白话解释 |
|---|---|
| 红利股 | 长期稳定、大方分红的公司股票，靠「收租」为主 |
| 股息率 | 每股分红 ÷ 股价，约等于「买这股票的年化收租率」 |
| TTM | 滚动十二个月（Trailing Twelve Months），最近一整年的数据 |
| EPS（每股收益） | 公司一年赚的钱 ÷ 总股数，等于「每股赚了多少」 |
| ROE（净资产收益率） | 净利润 ÷ 净资产，等于「钱生钱的效率」；12% 算满分线 |
| 派息比例 | 分红 ÷ 净利润，分出去的利润占赚到的多少；30%–70% 最健康 |
| 国债收益率 | 国家借钱付的利息（无风险利率），是判断股息率高低的坐标 |
| 波动率 | 股价上蹿下跳的幅度，越高越刺激（风险大） |
| OCF（经营现金流） | 公司主业实打实收到的现金；OCF/净利润 看利润含多少「水分」 |
| 价值陷阱 | 看着便宜、实际有雷，买了容易亏的公司 |
| 市盈率（PE） | 股价 ÷ 每股收益，等于「按当前盈利多少年回本」 |
| 戈登模型（DDM） | 用「未来分红折现」算公司内在价值的公式 |
| 板块中位数 | 同一行业所有股票某指标的中间值，用来比「这只算好还是差」 |

## 七、数据从哪来

用两家数据源、互为印证：

- **银河证券 AmazingData SDK**：行情（K 线）、财报、分红、10 年期国债利率的主源。账号凭证放在本地文件里，**不进仓库**。
- **akshare（东方财富）**：补充「经营现金流」数据，用来做现金流质量检验（七维检验口径）。

为什么两家？一家主、一家补，关键字段交叉印证，减少单源出错或缺失导致的误判。所有数据拉取完即断开连接。

## 八、给技术读者（架构与本地运行）

- **技术栈**：Python 3.13 + DuckDB（单文件本地库）+ Jinja2 渲染 + GitHub Pages 发布 + 飞书 webhook 通知 + OpenAI 兼容 LLM API；35 个 pytest 单测。
- **目录结构**：`config/*.yaml` 放参数与股票池；`src/hongli/` 下分 `xy`（唯一碰 SDK）、`ingest`（入库）、`metrics`（五因子纯函数）、`scoring`（合成+矩阵）、`llm`（点评+价格锚）、`report`（HTML）；`data/hongli.duckdb` 落库；`report/` 出周报。
- **本地跑**：
  ```bash
  py -3.13 -m venv .venv && .venv\Scripts\activate
  pip install -r requirements.txt
  # 另需手动安装银河 SDK 离线包（见 requirements.txt 顶部注释）
  .venv\Scripts\python.exe -m src.hongli.pipeline                 # 全流程（含数据拉取与 LLM）
  .venv\Scripts\python.exe -m src.hongli.pipeline --no-ingest    # 只用本地库重算（离线）
  .venv\Scripts\python.exe -m src.hongli.pipeline --asof 2026-09-04   # 指定日期重放
  ```
- **配 .env**：把 `HONGLI_LLM_API_KEY`、`HONGLI_LLM_BASE_URL`、`HONGLI_FEISHU_WEBHOOK`（飞书机器人推送地址）写进 `.env`（值不入仓库）；LLM 模型可用 `HONGLI_LLM_MODEL` 覆盖（默认 glm-4.7，可切 DeepSeek 等 OpenAI 兼容模型）。
- **定时任务**：Windows 任务计划程序（任务名 `hongli_weekly_friday`）每周五 18:00 触发 `run_weekly.bat`：清残留锁 → 跑流水线（含飞书通知）→ 把最新报告推上 GitHub Pages。全程日志写在 `run_schedule.log`。
- **配置即参数源**：所有阈值（估值带 0.40/0.65、目标息率 4.5%、波动率 25% 等）集中在 `config/base.yaml`，改 YAML 即可调策略，无需动代码。
- **铁律**：`metrics/` 纯函数不碰 SDK/数据库，保证可测可回测；LLM 只读不写因子表；缺失数据显式标记（宁缺毋造），缺失 ≥2 项因子则不给评级（灰色卡片）；同一时刻只允许一个流水线实例（`data/.lock` 文件锁）。
